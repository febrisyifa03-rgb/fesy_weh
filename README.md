# 🌸 Website Biodata Siswa: Syifa & Fesya (XII RPL 1)

Website profil dan biodata diri interaktif dengan tampilan modern, fitur **Live In-Browser Edit (Diedit Langsung di Web)**, dan **Dual Profile Switcher**.

---

## 📋 Bagian-Bagian Biodata yang Ditampilkan

1. **Profil Hero**: Foto profil berbingkai estetik, nama lengkap, nama panggilan, kelas, bio singkat, dan tombol navigasi.
2. **Data Diri Lengkap**:
   - Nama Lengkap & Panggilan
   - Tempat, Tanggal Lahir
   - Jenis Kelamin & Agama
   - Kewarganegaraan
   - Kelas / Jurusan
   - Hobi & Cita-Cita
3. **Riwayat Pendidikan**:
   - SMK Negeri 1 Kota (XII RPL 1)
   - SMP Negeri Kota
   - SD Negeri Kota
4. **Media Sosial**:
   - Kartu Instagram resmi yang diletakkan proporsional dan presisi tepat di tengah halaman.

---

## ✏️ Fitur Mode Edit Langsung di Web

Kamu bisa mengedit isi biodata secara bebas kapan saja:
1. Klik tombol **"Edit Biodata"** di kanan atas.
2. Klik teks apa pun untuk mengeditnya secara langsung.
3. Klik lingkaran foto profil untuk mengganti foto dari galeri laptop atau HP.
4. Klik tombol hijau **"Simpan"** untuk menyimpan perubahan secara permanen di browser (`localStorage`).
5. Klik **"Reset Awal"** jika ingin mengembalikan ke data template bawaan.
